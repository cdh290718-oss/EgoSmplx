# 验证报告

验证日期：2026-09-27。此报告对应本仓库简化路线 B，包含身体轮廓约束及固定七圈接缝，不包含额外腕部优化。没有沿用此前复杂融合版本的误差数字。

## 真实图像验证

使用 session_hand_6 左下、右下视频各四张，共八张 1280×720 图像，沿用已确认的 cam3/cam4 标定。八帧测试复用原始网络与自动观测缓存，重新运行全部 1800 步刚体拟合、1600 步身体点与轮廓拟合和固定规则融合。

另外对 sample_01_cam3 从原图重新执行 EgoSMPLX、Sapiens2 关键点、WiLoR、Sapiens2 分割，再完整执行拟合与融合，验证仓库自带的原生推理适配入口。最终相机与融合模块又独立重建八帧，顶点和面索引与保存结果一致。该测试与缓存复算的同一帧得到一致的汇总误差；没有把八帧缓存测试描述成八帧网络重推理。

八帧共匹配 16 只手；身体统计 100 个有效自动点，手部统计 336 个自动点。汇总身体点 RMSE 为 **32.97 像素**，手部点 RMSE 为 **13.90 像素**。参考均为模型自动点，不是人工真值。

## 重载及拓扑

八帧全部通过身体参数重建、融合配方重建和 OBJ/NPZ 对照。身体和融合网格重载的最大顶点差为 0 米；导出的浮点 OBJ 与 NPZ 一致。各帧最终几何满足既定正向深度检查，16 只手的接缝及内部边均通过两相邻面的绕序检查。

这些验收不证明全身无自交，也不证明腕部轮廓正确。代码没有使用人工关节点作为拟合输入。

## 模型无关检查

11 项单元测试在实际 body_python 环境中通过，覆盖点 RMSE 定义、径向距离反投影、手部一对一匹配、低置信及缺失手、边界环距离与断开拓扑、JSON/NPZ 有限数值、变量展开、路径安全，以及独立相机的轴变换、径向深度与可微投影。Python 源码编译与 Bash 入口语法检查通过。

本报告的验证范围是八帧后处理和一帧完整推理，不是大规模精度评估，也不是跨机器自动安装验证。外部后端仍需按部署说明准备。
