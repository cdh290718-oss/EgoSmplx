# 指定 results_bundle.zip 的生成流程

本说明以 `session_hand6_full_pipeline_20260926_v1/results_bundle.zip` 的实际内容为准。目标是解释、保存并复现这批结果的生成方法。

- ZIP SHA-256：`19b9baf80998dbd3f6f0da8f620295251d97a2c9aeeb7c2d282d5c31835e7fd6`。
- 输入：session_hand_6 左下、右下两段视频各 4 帧，共 8 张，1280×720。
- 标定：用户确认沿用 cam3 左下、cam4 右下相机标定。
- 自动目标：Sapiens2 身体点与分割、WiLoR 手部预测。没有读取人工标注。
- 原始记录：ZIP 中的 `scripts/`、`RUN_REPORT_zh.md`、`summary.json`、`delivery_validation.json` 和逐帧配方。

此前仓库首次发布的“简化路线 B”与这个 ZIP 的实际生成流程不一致。当前版本已按这个指定结果纠正：轮廓约束在身体两阶段拟合之后加入，最终融合包含有界腕点校正、轮廓候选选择与局部谐波表面连接。原先简化版的实验数据不作为本结果的验证数据。

## 1. 三列结果分别是什么

| ZIP 中的目录 | 展示内容 | 已执行的处理 |
|---|---|---|
| `01_raw` | 原始 EgoSMPLX 网格投影 | 直接使用网络朝向、平移和姿态，未进行自动点校正 |
| `02_sapiens2_body` | 身体校正后的标准 SMPL-X 网格投影 | 刚体优化 1800 步，再优化 19 个身体关节 1600 步 |
| `03_fusion` | SMPL-X 身体＋MANO 手部融合网格投影 | 自动手部匹配、有界腕点校正、轮廓候选选择、鱼眼反投影、局部谐波表面连接 |

第二列和第三列的身体参数也可能不同。第三列不是只把第二列的手指换掉：后续腕点与轮廓拟合还会在原有约束内微调身体姿态。

## 2. 视频抽帧和自动预测

每段视频按 12.5%、37.5%、62.5%、87.5% 的位置取帧，约为 9.7、29.1、48.5、67.9 秒，未根据拟合效果挑选图片。两台相机分别处理，这些采样位置不代表已经验证严格时间同步。

EgoSMPLX 使用 `snapshot_11.pth.tar`，实验目录为 `train_5datasets_8gpu_camtrans_w10_12ep_fixed_20260809_20260809_163018`。从预测文件恢复 `global_orient_network` 和 `transl_network`，与其余 SMPL-X 参数一起重建真正的原始网络网格。

Sapiens2 使用 1B pose 权重输出 308 点，并使用 1B segmentation 权重输出 29 类分割标签和概率。身体拟合只映射其中 13 个身体点；置信度低于 0.3、非有限数值、落在图外的点剔除。八帧合计保留 100 个身体目标点。

WiLoR 使用原版 `pretrained_models/wilor_final.ckpt`，不是后来讨论的 egocentric 微调权重。记录 MANO 局部顶点、关节、相机平移、二维点和检测信息；本结果的投影约定为 1280×720、针孔焦距 25000 像素。

## 3. Sapiens2 两阶段身体校正

第一阶段只更新 `global_orient` 和 `transl`，共 1800 步。身体姿态、体型、手指和面部参数不动。残差由鱼眼投影的身体关节点与 Sapiens2 自动点相减得到，使用按宽高归一化的 Smooth L1，并保留朝向、平移先验和深度限制。

第二阶段更新 19 个 `body_pose` 关节，并允许全局朝向和平移微调，共 1600 步。左右脚、体型 `betas`、手指和面部参数固定；全局轴角增量范数不超过 8°。各关节仍采用既有角度增量上限，腕点距离至少为刚体初值的 85%，所有网格顶点 z 不小于 0.02 米。

这个阶段没有分割轮廓损失。保存的 `02_sapiens2_body` 就停在这里。更详细的角度与损失系数见设计说明书及 `body_common.py`、`body_pose.py`。

## 4. 手部身份匹配与初始融合

对每张新图自动匹配一次左右手：优先以可信的 Sapiens2 腕点为位置锚点，退回标准身体腕点；综合 WiLoR 检测置信度、腕点距离和左右类别，选取一对一分配。一个 WiLoR 检测不能重复分配给两侧。后续所有优化冻结这个匹配身份，不使用分割的左右类别重新分配。

先生成基线融合。MANO 原图投影整体平移至身体腕点，像素位置按鱼眼标定反投影为射线；径向距离由身体腕点距离加上 MANO 相对径向深度确定。这保留手部投影形状和尺寸，同时使根部跟随身体腕点。

基线使用固定 7 圈 smoothstep 混合，作为后续比较与回退对象。它不是这个 ZIP 最终表面的完整算法。最终步骤还会重建手部并求解局部谐波位移；删除基线或删除后续步骤，都属于不同的算法版本，不能称为生成同一个结果的原流程。

## 5. 有界腕点校正

先执行 500 步拟合，再以前次结果为初值执行 400 步带约束投影的拟合。目标是在不改变体型和骨长的前提下，让身体腕点更接近已匹配 WiLoR 腕点，并减轻腕环投影半径与手部目标的不兼容。

优化变量仍是有界的身体姿态增量、全局朝向和平移。目标包含 Sapiens2 身体残差、4 倍权重的 WiLoR 腕点残差、腕环半径项、原有先验及深度/腕距屏障。

候选必须满足既有姿态上限和深度限制；身体自动点 RMSE 不能比第二阶段增加超过约 5 像素，腕点误差也有退化上限。每次更新可以投影回约束范围，并通过回退步长拒绝不可行更新。优化保留最好的可行候选，不保证全局最优。

## 6. 可见前臂轮廓候选

先用腕点校正后的身体生成并冻结轮廓观测。前臂轴线由 **Sapiens2 肘点和已匹配的 WiLoR 腕点** 确定，分割只使用臂手类别 `[6,7,11,15,16,20]` 的并集，避免左右语义误分类。

沿肘腕轴线的 0.15–0.88 区间取 12 条横截线，要求概率并集大于 0.55、连续宽度至少 8 像素且两端可见；至少有 3 条可靠横截线才启用该侧约束。不为被物体遮挡的边界补造轮廓目标。

损失包含两部分：身体前臂顶点投影超出分割区域的距离，以及观测边界到顶点投影的覆盖距离。体型不变，主要通过姿态和刚体参数调整投影。

分别从腕点校正结果出发运行两组 400 步候选：轮廓权重 0.08 和 0.4。与未增加轮廓拟合的既有候选一起，使用同一套打分和硬约束选优。强轮廓分支还把腕环顶点加入约束。本 ZIP 的 8 帧均选中 `strong` 候选；新图不应预先强制选中它。

## 7. 最终 MANO 连接与局部表面调整

根据选中的身体姿态重新生成标准 SMPL-X 身体，再重新把 MANO 投影沿鱼眼射线提升到三维。手指姿态和投影形状来自 WiLoR/MANO。

以当前体型对应的标准腕环为几何参照，构造有界候选：朝手部对齐的候选，以及有限旋转与半径组合。朝向校正限制在 30°，目标半径缩放范围为 0.9–1.1，腕环中心位移不超过 0.015 米。

身体侧在腕环附近的拓扑邻域内、手部侧在近腕邻域内求解固定边界的稀疏拉普拉斯方程，将连接位移平滑传播；远处身体和手指不任意拖动。实现使用身体侧 `0 < d < 10`、手部侧 `0 < d < 7` 的自由顶点，腕环与外围顶点作为边界。这是局部谐波位移求解，与“只做固定七圈 smoothstep”不同。

候选要通过边长比、三角形面积、法向、腕环半径、深度及手部重投影退化检查，并综合可见轮廓选优。没有合格且更好的候选时保留基线。该检查不保证没有所有形式的自交，也不能保证视觉上完全自然。

最终手部骨架由最终网格回归，避免显示的骨架和实际手部表面不一致。

## 8. 保存与验收

每帧保存三组投影图；前两组有标准 SMPL-X 参数和 OBJ，第三组有身体基底参数、显式融合网格 NPZ/OBJ、手部自动预测、匹配身份、轮廓目标与几何验收报告。

最终 `body_params.npz` 定义身体基底，不能单独恢复 MANO 替换和局部表面位移。重建第三组必须同时使用手部预测、标定、冻结身份和轮廓目标，或直接读取 `hybrid_mesh.npz` / `hybrid_mesh.obj`。

RMSE 以自动二维点为参考：`sqrt(mean((u_pred-u_auto)^2 + (v_pred-v_auto)^2))`，单位为原图像素。跨帧汇总全部点后开方，不对每帧 RMSE 做简单平均。

| 指标 | 第二列：身体校正 | 第三列：最终融合 |
|---|---:|---:|
| 身体 100 点 RMSE | 37.12 px | 31.96 px |
| 手部 336 点 RMSE | 84.12 px | 4.41 px |
| 匹配手数 | 同一组身份 | 16 |

以上是指定历史 ZIP 的数据，不是人工真值精度，也不是重新训练模型的结果。sample_04/cam3 仍有身体偏差和右腕外扩，三个病例的身体点误差略升。不能根据重载成功宣称外观完全正确。

### 从图像运行完整流程

按 README 和部署说明填写模型资源路径、输入清单和新输出目录，然后执行：

```bash
python3 -m egosmplx_pipeline run --config .local/pipeline.json
```

若已有同图自动预测，添加 `--cached-predictions`，仍重新运行 1800/1600 步身体拟合和完整后续腕点、轮廓与表面流程。当前参考配置针对本批 1280×720 图像；未验证其他分辨率。

完整运行完成后，用以下命令导出新的可分享结果包：

```bash
python3 -m egosmplx_pipeline.package \
  --run /data/results/new_run --archive /data/results/results_bundle_new.zip
```

新包包含三阶段结果、原图、标定、自动点、最终网格重建输入和源码，并附带逐文件 SHA-256。新包目录布局与历史 ZIP 略有不同，不覆盖历史结果，也不承诺 ZIP 压缩字节完全相同。

### 精确重建这个 ZIP 中的最终网格

该命令使用 ZIP 中已经保存的最终身体参数和自动观测，不重新推理网络或重新执行优化。用它检查迁移后的融合代码是否确实生成同一个最终结果：

```bash
"$BODY_PYTHON" -m egosmplx_pipeline.reference.rebuild_archive \
  --archive "$RESULTS_BUNDLE" \
  --repo-root "$EGOSMPLX_REPO" \
  --config "$EGOSMPLX_MODEL_CONFIG" \
  --output /data/results/archive_rebuild_new
```

以上变量需填写实际路径。2026-09-27 已核对 ZIP 内全部 374 个受清单保护的文件，并独立重建 8 帧最终网格：所有 NPZ 网格字段逐值完全相同，顶点最大绝对差为 0 米。记录见 `archive_reconstruction_validation.json`。这证明最终几何重建一致，不代表从视频重新执行所有模型会得到逐位一致的预测。

ZIP 不含网络权重、SMPL-X/MANO 模型资源及大型分割概率缓存；仅凭 ZIP 无法从头重新推理所有网络。最终网格重建使用其中冻结的轮廓目标及分割标签，完整优化则需要模型和分割概率缓存或重新生成这些观测。
