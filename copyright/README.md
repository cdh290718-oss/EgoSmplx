# 软著申请准备材料

软件名称：**第一视角下视双目鱼眼相机估计身体姿态软件**；简称：EgoSmplx；版本：V1.0。

`generated/` 提供由本仓库当前源码与文档导出的文件：

- `01_登记信息填表稿.docx`、PDF：可直接编辑的字段草稿。
- `02_软件设计说明书.docx`、PDF：与实际简化流程对应的设计说明。
- `03_源程序文档_完整.docx`、PDF：确定顺序的实际源码。
- `03_源程序文档_交存.docx`、PDF：完整材料超过 60 页时取前后各 30 页，否则交付全部。
- `04_权属核对与提交清单.docx`、PDF。
- `source_inventory.json`：文件 SHA-256、实际行数、分页与截取规则。

使用 `python3 tools/export_copyright.py` 可重新生成。源码打印按每页 50 行可见源码排版，末页除外；长行只在打印时续行，不修改仓库源码。不通过填充无关程序凑页数。

申请人仍须如实填写权利人、开发方式、开发完成日期、历史首次发表时间地点，并准备相应身份证明及实际需要的权属/授权证明。公开仓库不放身份证号码、联系地址、签章或证明扫描件。

鉴别材料的前后页、全部交存及行数依据参考[国家版权局《计算机软件著作权登记办法》第十条](https://www.ncac.gov.cn/xxfb/flfg/bmgz/202410/t20241015_869486.html)，2026-09-27 核对。导出文件属于准备稿，最终填报应与申请人真实情况和受理要求一致。

本次 GitHub 公开记录是一个可核验的发布记录，不能直接认定为软件历史首次发表日期。软件源码、参数化人体模型和外部神经网络的权利范围应分别核实。
