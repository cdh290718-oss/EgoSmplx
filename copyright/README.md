# 软著申请准备材料

`generated/` 提供由本仓库当前源码与文档导出的文件：

- `01_登记信息填表稿.docx`、PDF：可直接编辑的字段草稿。
- `02_软件设计说明书.docx`、PDF：按 GB 8567-88 的概要设计、详细设计提纲编排，包含架构、流程、接口、数据结构、优化约束、真实推理结果及验证图表。

- `03_源程序文档_交存.docx`、PDF：完整材料超过 60 页时取前后各 30 页，否则交付全部。
- `04_权属核对与提交清单.docx`、PDF。
- `source_inventory.json`：文件 SHA-256、实际行数、分页与截取规则。

本次材料同步 2026-09-30 当前默认流程；保留名称及登记版本 V1.0，未代填申请人事实。

本次导出：设计说明书 21 页、7 幅图；源程序完整稿 139 页，交存稿 60 页。说明书采用参考稿的黑体标题、宋体正文、黑色三线表与居中插图，正文分为软件概述、环境、功能、核心模块、技术特点、流程、数据、使用说明、异常恢复、测试结果、版本限制、第三方组件和维护说明十三章。概要设计与详细设计的内容对应关系另见 [DESIGN_GB8567_INDEX.md](../docs/DESIGN_GB8567_INDEX.md)。结果图片与数据来自仓库已有推理和验证记录。

仅重生成本次设计说明书，运行 `python copyright/build_design_reference.py`。如需重生成全部材料，先运行 `python tools/export_copyright.py --only all`，再运行上述设计说明书命令，以应用本次参考版式。Windows 使用已安装的 Word 更新目录并导出 PDF。代码材料按申请人提供的参考稿设置为 A4、Times New Roman／宋体 9.5 磅、固定 14 磅行距，每 5 行显示行号；每页 50 行可见内容，完整稿末页除外。长行只在打印时续行，不修改仓库源码。完整版式与重生成方法见 [FORMAT_SPEC.md](FORMAT_SPEC.md)。

此次只修订设计说明书及其图文资源。源程序文档、源码清单及原有 48 个源文件保持不变；已核对源文件摘要和源程序鉴别材料与上一版一致。
